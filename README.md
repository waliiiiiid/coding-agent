\# 🤖 AI Coding Agent



An AI-powered coding agent that can \*\*write, review, debug, and test code\*\* — not just by analyzing syntax, but by actually executing it inside an isolated Docker sandbox.



\## ✨ Features



\- \*\*💻 Code Generation:\*\* Write and modify code based on natural language instructions.

\- \*\*🔍 Smart Code Review:\*\* Detect bugs, logical errors, and potential issues beyond syntax.

\- \*\*🐳 Docker Execution:\*\* Run code in an isolated Docker sandbox and analyze real execution results.

\- \*\*🛠️ Custom Skills \& Instructions:\*\* Customize the agent's behavior with your own instructions and reusable skills.

\- \*\*🔗 GitHub Integration:\*\* Connect and work with GitHub repositories.

\- \*\*📦 ZIP Import:\*\* Upload your own project as a ZIP folder and let the agent analyze and modify it.



\## ⚙️ How It Works



1\. Connect a GitHub repository or upload a ZIP project.

2\. Give the agent a coding task or request a code review.

3\. The agent analyzes and modifies the code.

4\. Code is executed inside a Docker sandbox.

5\. The agent analyzes the results and improves its solution.



\## 🧰 Tech Stack



\- \*\*Backend:\*\* FastAPI

\- \*\*Frontend:\*\* Streamlit

\- \*\*Execution Environment:\*\* Docker

\- \*\*AI:\*\* LLM-powered coding agent



\## 🚀 Goal



Go beyond AI-generated code with an agent that can actually execute, test, and validate its work.
